# Состояние проекта

## Что включено в эту сборку
- Переработанное главное меню в духе аркадного Geometry Dash: крупная кнопка игры, навигация к уровням, скинам, редактору и настройкам.
- Кампания из 22 уровней с возрастающей скоростью, BPM, палитрами и сложностью.
- Первые четыре уровня используют вручную заданные схемы препятствий; уровни 5–22 получают отдельные детерминированные схемы, которые генерируются из номера уровня.
- В игровом ядре уже есть кубик, корабль, шар, шипы, блоки, пилы, платформы, прыжковые площадки, сферы, прогресс, пауза, перезапуск, сохранение рекорда и генерируемая Web Audio музыка.
- 26 графических ассетов скинов, экран скинов, настройки и редактор уровней с локальным сохранением и импортом/экспортом JSON.
- Настроен GitHub Actions для статической QA, TypeScript/Vite build и Windows installer.

## Чего не следует считать завершённым
- Это не точные копии геометрии официальных уровней и не официальный контент RobTop. Это собственная кампания, вдохновлённая темпом и сложностью классических уровней.
- Полный игровой режим wave, spider, robot, swing и платформерные башни ещё не реализованы как самостоятельные физические режимы.
- Пользовательская карта из редактора пока не запускается прямо в основном движке.
- В этой среде прошла статическая QA-проверка. Полную сборку TypeScript/Vite и Windows `.exe` нужно подтвердить в GitHub Actions; локальная установка npm-зависимостей здесь завершилась по таймауту.
