# Исправление кастомных скинов — GPT

## Причина

Пути в `src/data/skin-assets.ts` начинались с `/assets/icons/...`. В Electron при запуске через `file://` такой абсолютный путь разрешается от корня диска, а Vite не копирует папку `assets/` проекта в `dist` автоматически.

## Исправление

- Пути кастомных скинов переведены на относительные: `./assets/icons/<имя>.png`.
- Все 26 PNG скинов скопированы в `public/assets/icons/`. Vite копирует содержимое `public` в `dist`, поэтому итоговые изображения доступны по `dist/assets/icons/...`.
- В `scripts/qa-static.mjs` добавлена проверка всех 26 путей и запрет абсолютных `/assets/icons/...` путей.

## Проверки

- `node scripts/qa-static.mjs` — успешно.
- `npm install --no-audit --no-fund` в этой среде не завершился за отведённое время; поэтому `npm run build` и сборка Windows здесь не подтверждены.

## Проверка на Windows

Из корня проекта запустить:

```bash
npm install
npm run qa:static
npm run build
npm run dist:win
```

Затем открыть экран «Скины», выбрать несколько кастомных иконок и запустить уровень. Проверить, что изображения видны и в предпросмотре, и на кубике во время игры.
