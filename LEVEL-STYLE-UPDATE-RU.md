# Обновление игрового уровня — белый/фиолетовый стиль

Что изменено:
- игровой фон заменён на белый с очень лёгкой сеткой;
- фиолетовые платформы с мягкими углами и светлой верхней гранью;
- чёрные круглые опасности;
- оранжевые сферы и прыжковые площадки;
- пунктирные дуги прыжка;
- HUD, полоса прогресса и подсказка приведены к светлой теме.

Сохранены существующие меню, выбор уровней, скины, управление, столкновения и конфигурация сборки Windows через GitHub Actions.

Проверка: `node scripts/qa-static.mjs` проходит. Полная TypeScript/Vite-сборка не подтверждена в текущем окружении: зависимости Vite не были доступны для установки.
