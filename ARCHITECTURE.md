# Geometry Dash: архитектура

## Стек
| Слой | Выбор | Почему |
|---|---|---|
| Язык | TypeScript (strict) | Типы для формата уровней и объектов, меньше багов в игровой логике |
| Сборка | Vite | Мгновенный dev-сервер и HMR, простая production-сборка |
| Рендер игры | PixiJS v8 (WebGL/WebGPU) | Быстрый 2D с батчингом спрайтов, частицы, шейдеры/фильтры |
| Меню и UI | DOM + CSS | Анимации, доступность, адаптивность без лишнего кода |
| Физика | Собственная (фикс. шаг 240 Гц, AABB) | GD детерминирован и тайловый, готовый движок только мешает |
| Звук | Web Audio API | Точная синхронизация с музыкой уровня |
| Сохранения | localStorage (`gd.save.v1`) | Прогресс, скин, настройки |
| Десктоп (позже) | Electron или Tauri | Упаковка в .exe при необходимости |

## Структура
```
src/
  core/store.ts       сохранения: настройки, скин, прогресс
  data/               описание уровней и скинов
  game/               геймплей (этап 2+): loop, player, world, level loader, audio
  ui/                 DOM-слой: router, screens/, background, cube
  main.ts             точка входа
```
Правило: `ui` вызывает `game` только через `game/index.ts`, `game` не знает про DOM-меню.

## Этапы
1. Архитектура и главное меню (готово)
2. Игровой цикл, игрок-куб, физика, камера
3. Формат уровней и объекты: шипы, блоки, порталы, батуты
4. Музыка, смерть/респаун, прогресс, монеты
5. Остальные режимы (корабль, UFO), частицы, эффекты
6. Редактор уровней, упаковка
