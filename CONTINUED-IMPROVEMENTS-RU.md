# Продолжение доработки Geometry Dash Custom

## Что интегрировано в проект

1. **Пауза**: кнопка в HUD и клавиша Escape; игровой прогресс останавливается, мастер-громкость приглушается. В окне паузы доступны продолжение, рестарт и возврат в меню.
2. **Обучение при первом запуске**: краткие подсказки по прыжку, кораблю и паузе. Результат сохраняется в localStorage.
3. **Приземление на платформы**: добавлена проверка пересечения верхней поверхности платформы при падении в режиме куба.
4. **Клавиша Escape**: глобальный обработчик маршрутизации больше не перехватывает Escape во время уровня.
5. **PWA и favicon**: добавлены размеры иконок 192×192 и 512×512, ссылки favicon 16/32 и manifest с корректными путями.

## Проверка

- Запустить `npm install`.
- Запустить `npm run build`.
- Запустить `npm run dev` и открыть уровень.
- Проверить первый запуск обучения, Space/клик, Escape для паузы, продолжение, рестарт, платформу и возврат в меню.
- Проверить сборку `npm run dist:win` на Windows или через GitHub Actions.

В текущей среде `npm install` не завершился в доступное время, поэтому сборка TypeScript/Vite здесь **не подтверждена**. Перед публикацией обязательно проверьте её через GitHub Actions.

## Что ещё остаётся

- Орбы: стоит перевести их на явную активацию по нажатию с отслеживанием использованного orb за попытку.
- Физику платформ/режимов нужно тестировать на всех уровнях и скоростях; текущая правка — базовая, не полноценная физическая симуляция.
- Звук всё ещё процедурный, отдельные ползунки музыки/SFX и полноценные музыкальные дорожки требуют отдельной интеграции.
- Рекомендуется автоматизировать smoke-тесты уровней и проверить Windows-установщик на чистой машине.
