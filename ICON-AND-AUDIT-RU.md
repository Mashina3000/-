# Иконка и аудит Geometry Dash Custom

## Концепт иконки
Неоновый геометрический куб с выразительными глазами, светящимся порталом и шипом. Куб и шип считываются как платформенный ритм-раннер, портал намекает на смену режимов. Квадратная композиция и высокий контраст помогают узнаваемости в маленьком размере.

## Стили на выбор
1. **Минимализм:** плоский куб, два глаза, один шип, 2–3 цвета, почти без свечения.
2. **Неон (текущий):** сине-фиолетовый фон, золотой куб, циановый контур и портал.
3. **Мультяшный:** мягкие грани, более дружелюбное выражение, насыщенные тёплые цвета.

## Технические файлы
- `assets/icons/app-icon.svg` — редактируемый SVG-источник 1024×1024.
- `assets/icons/app-icon.png` и `app-icon-1024.png`, `app-icon-512.png`, `app-icon-256.png`, `app-icon-128.png`, `app-icon-64.png`, `app-icon-32.png`, `app-icon-16.png`.
- `assets/icons/app-icon.ico` — multi-size ICO для Windows/Electron.
- `public/icon.svg`, `public/icon.png`, `public/favicon-32.png`, `public/favicon-16.png`, `public/manifest.json` — веб-иконка/PWA.
- Safe zone: 10%; силуэт и портал остаются внутри центральной области.

### Экспорт вручную
Можно открыть SVG в Inkscape или браузере и экспортировать PNG. Для ICO можно использовать icoconvert.com, загрузив PNG и выбрав несколько размеров. Для SVG→PNG также подойдут SVGtoPNG или Inkscape. В проекте готовые PNG/ICO уже созданы.

### Читаемость
**32×32:** читаются золотой куб, контрастные глаза, голубой контур и портал.
**16×16:** останутся общий квадрат, яркое лицо и пятно портала; мелкая сетка и тонкие линии частично потеряются — это ожидаемо. Для строго 16px-ориентированного favicon лучше использовать упрощённый вариант без сетки и свечения.

## Примеры кода must-have

### 1. Исправление рестарта
Файл: `src/game/index.ts`, функция `onKey`. Теперь при `dead || won` Space/Enter обрабатываются до обычного прыжка, что устраняет недостижимую ветку перезапуска.

### 2. Подключение иконки
Файлы: `index.html`, `public/manifest.json`, `electron.cjs`, `package.json`. SVG/PNG доступны веб-приложению, ICO используется electron-builder на Windows.

### 3. Проверка сборки
Выполнить `npm install`, `npm run build`, `npm run dist:win`. Для CI стоит добавить отдельный шаг `npm run build` до упаковки или оставить текущую команду `dist:win`, которая уже запускает сборку.
