# QA-отчёт Geometry Dash Custom

## Что проверено в этой сборке

- JSON-синтаксис `package.json` и `public/manifest.json`.
- Наличие исходных файлов, иконок, favicon и Windows ICO.
- Наличие и доступность файлов иконок, перечисленных в PWA manifest.
- Ссылки на favicon и manifest в `index.html`.
- Статические маркеры интеграции паузы, обучающей подсказки, платформ, одноразовой активации орбов и очистки музыкального таймера.
- Путь к Windows ICO в `electron.cjs`.
- Заголовки PNG/ICO.

Результат: `node scripts/qa-static.mjs` прошёл успешно.

## Исправления в этой версии

1. Орб можно активировать только один раз за попытку; при рестарте создаётся новый набор активаций.
2. Таймер процедурной музыки очищается при выходе, рестарте и завершении уровня.
3. Защита от создания нескольких `AudioContext` при повторном вводе во время запуска звука.
4. Процедурная музыка стартует приглушённой, если при первом запуске показано обучение.
5. Electron использует ICO, который включён в конфигурацию сборки, вместо PNG, не гарантированного в упакованных файлах.
6. Добавлен `npm run qa:static` и его запуск в GitHub Actions перед TypeScript/Vite build.

## Что не удалось подтвердить в этой среде

`npm install --no-audit --no-fund` не завершился в отведённое время. Поэтому `npm run build`, запуск игры в браузере/Electron и создание Windows installer здесь не подтверждены. Глобальный `tsc --noEmit` остановился на отсутствии `vite/client`, поскольку зависимости проекта не установлены.

## Обязательная проверка на GitHub Actions

После загрузки архива в репозиторий workflow должен пройти шаги:

1. Install dependencies
2. Static project checks
3. Type-check and build web app
4. Package Windows installer
5. Upload installer artifact

Успешный статический QA сам по себе не подтверждает прохождение уровней или корректность игрового баланса. Перед релизом нужно вручную проверить каждый уровень, паузу, рестарт, платформы, орбы, звук, сохранения и установку на чистой Windows.
